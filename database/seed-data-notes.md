# Seed Data Notes

> Documents the synthetic seed data generated by `src/data_generation/generate_sample_data.py`.
> Explains why intentional quality issues were introduced and how they map to Silver layer checks.

## Overview

All three CSV files are synthetic — no real customer or order data was used.
The data is generated locally using `pandas` and `faker`.

| File | Rows | Quality issues seeded |
|---|---|---|
| customers.csv | 10,000 | 120 (across 4 categories) |
| orders.csv | 100,000 | 580 (across 9 categories) |
| products.csv | 500 | 0 |
| **Total** | **110,500** | **700** |

## Why Quality Issues Were Introduced

The Silver layer implements four quality checks (Completeness, Uniqueness,
Type Validation, Referential Integrity) plus a Business Logic check. Without
seeded defects, there would be no way to verify these checks actually work.
The 700 seeded issues provide true positive test cases for every check category.
